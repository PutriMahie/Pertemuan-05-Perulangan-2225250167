## Algoritma Kuis 2

Langkah-langkah perulangan untuk menyelesaikan deret aritmetika:

1. Masukkan nilai suku pertama.
2. Masukkan nilai beda deret.
3. Masukkan jumlah suku yang ingin ditampilkan.
4. Tentukan nilai awal jumlah deret yaitu 0.
5. Lakukan perulangan sebanyak jumlah suku.
6. Hitung nilai setiap suku berdasarkan suku pertama, beda, dan urutan suku.
7. Tampilkan setiap suku deret.
8. Tambahkan setiap suku ke dalam jumlah deret.
9. Setelah perulangan selesai, tampilkan jumlah seluruh deret.

## Hasil Pengujian

| Input               | Keluaran yang Diharapkan | Keluaran Aktual          | Status   |
| ------------------- | ------------------------ | ------------------------ | -------- |
| a = 2, b = 3, n = 5 | 2 5 8 11 14, jumlah = 40 | 2 5 8 11 14, jumlah = 40 | Berhasil |

## Refleksi

Kesalahan perulangan yang ditemukan adalah lupa menambahkan nilai setiap suku ke variabel jumlah. Akibatnya, program hanya menampilkan deret tanpa menghitung jumlah seluruh suku. Kesalahan tersebut diperbaiki dengan menambahkan setiap nilai suku ke variabel jumlah di dalam perulangan.
